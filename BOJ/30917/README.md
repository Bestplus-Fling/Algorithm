# [BOJ 30917 - A+B - 10 (제1편)](https://www.acmicpc.net/problem/30917)
- 난이도: 브론즈 3
- 분류: 구현, 브루트포스
- 날짜: 2026-02-05
- 제출: 1회

## 문제
- 1 이상 9 이하의 정수 A, B에 대해 A+B의 값을 출력
- A와 B의 값이 바로 주어지지 않고, 채점기와의 상호작용을 통해 그 값을 알아내야 한다.

## 조건
- 채점기에 **최대 18번** 질문할 수 있다.
- 질문 형태
    - `? A x`: A의 값이 x인지 물어본다.
    - `? B x`: B의 값이 x인지 물어본다.
- 질문의 답이 "예"인 경우 1, "아니요"인 경우 0이다.
- A와 B의 값을 알아냈으면 A+B를 계산하여 다음과 같은 형태로 출력한다.
    - `! x`: A+B의 값은 x이다.
    - 이는 질문 횟수에 포함되지 않는다.

## 접근
- 1부터 9 사이의 수인지 확인하면 됨
- 질의의 최대 횟수는 18번이므로 A 9번, B 9번을 질의할 수 있음
- 반환된 값의 합을 출력
