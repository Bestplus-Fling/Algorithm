# [BOJ 25325 - 학생 인기도 측정](https://www.acmicpc.net/problem/25325)
- 난이도: 브론즈 3
- 분류: 구현, 자료구조, 문자열, 브루트포스, 집합과 맵
- 날짜: 2026-02-23

## 문제
- 요리하는 과정에서 정확히 하나의 요리 재료를 빼먹었다는 것을 떠올렸다.
- 현빈이가 요리하는 과정에서 무슨 재료를 빼먹었는지 맞혀보자.

## 조건
- 봉골레 파스타를 만들기 위한 요리 재료 종류의 개수 N이 주어진다.(2 ≤ n ≤ 1000)
- N 가지의 재료 중 현빈이가 사용한 N-1가지의 요리 재료가 공백으로 구분되어 주어진다. 
- 같은 요리 재료가 2번 이상 주어지는 경우는 없다.
- 각 재료는 알파벳 대/소문자로 이루어져 있고 길이 20 이하의 문자열이다.
- 같은 철자를 가진 요리 재료이더라도, 대소문자의 여부가 다르다면 두 요리 재료는 다른 요리 재료이다.

## 접근
- 첫 입력을 set 자료형으로 저장한다.
- 이후 나온 재료를 remove한 뒤 남은 재료를 출력한다.
