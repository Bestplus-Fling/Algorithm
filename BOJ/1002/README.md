# [BOJ 1002 - 터렛](https://www.acmicpc.net/problem/1002)
- 난이도: 실버 3
- 분류: 기하학
- 날짜: 2026-02-19

## 문제
- 조규현의 좌표 (x1, y1)와 백승환의 좌표 (x2, y2)가 주어지고,
- 조규현이 계산한 류재명과의 거리 r1과 백승환이 계산한 류재명과의 거리 r2가 주어졌을 때
- 류재명이 있을 수 있는 좌표의 수를 출력하는 프로그램을 작성하시오.
- 류재명이 있을 수 있는 위치의 개수가 무한대일 경우에는 -1 출력한다.

## 조건
- -10,000 ≤ x1, y1, x2, y2 ≤ 10,000 
- 1 ≤ r1, r2 ≤ 10,000

## 접근
- 1. 규현과 승환의 좌표가 같고 r1 == r2일 때 => -1(좌표 및 원이 같기 때문)
- 2. 규현과 승환의 거리가 r1 + r2 또는 r1 - r2의 절댓값과 같을 때
    - 두 점이 떨어져 있으나 접점이 1개인 경우 => 1
- 3. 규현과 승환의 거리가 r1 - r2보다 크고, r1 + r2보다 작을 때
    - 이때는 원의 교점이 있으며 2곳 => 2
- 4. 그 외 모든 경우 0
