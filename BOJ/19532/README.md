# [BOJ 19532 - 수학은 비대면강의입니다.](https://www.acmicpc.net/problem/19532)
- 난이도: 브론즈 2
- 분류: 브루트 포스, 수학
- 날짜: 2026-02-02
- 제출: 2회
  - 1회: 접근 1 정답
  

## 문제
- ax + by = c, dx + ey = f인 연립 방정식을 만족하는 x, y의 해를 구한다.

## 조건
- -999 <= a, b, c, d, e, f <= 999
- 방정식을 만족하는 x, y가 유일하게 존재한다.
    - 이때 x와 y가 각각 -999 이상 999 이하의 정수인 경우만 입력으로 주어짐이 보장된다.

## 접근
### 1. 완전탐색
- -999부터 999까지 x와 y 이중 for문을 통해 두 식을 동시에 만족하는 i, j를 출력하는 방법
### 2. 가감법
- x와 y를 같게 하기 위해 다음과 같은 방법을 사용
  - x에 대한 방정식이 성립하기 위해서 y의 지수를 같게 해야 한다.
    - 따라서 `ax + by = c`에 `(2)`번 식의 `y`의 지수 `e`를 곱한다
      - `aex + bey = ce`
    - `(2)`번 식 또한 y의 지수를 같게 하기 위해 `(1)`번 식 `y`의 지수 b를 곱한다.
      - `bdx + bey = bf`
    - 뺄셈을 하면 `(ae - bd)x + (be - be)y = ce - bf`
    - x에 대한 식으로 만들면 `x = (ce - bf) / (ae - bd)`
  - 위 방법으로 y 또한 구할 수 있다.
