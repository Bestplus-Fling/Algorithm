# [BOJ 2775 - 부녀회장이 될테야](https://www.acmicpc.net/problem/2775)
- 난이도: 브론즈 1
- 분류: 수학, 구현, 다이나믹 프로그래밍
- 날짜: 2026-02-23

## 문제
- a층의 b호에 살려면 자신의 아래(a-1)층의 1호부터 b호까지 사람들의 수의 합만큼 사람들을 데려와 살아야 한다
- 아파트에 비어있는 집은 없고 모든 거주민들이 이 계약 조건을 지키고 왔다고 가정했을 때, 주어지는 양의 정수 k와 n에 대해 k층에 n호에는 몇 명이 살고 있는지 출력하라.
- 단, 아파트에는 0층부터 있고 각층에는 1호부터 있으며, 0층의 i호에는 i명이 산다.

## 조건
- 1 ≤ k, n ≤ 14

## 접근
- 2차원 배열을 생성한다. 1차원은 k + 1만큼, 2차원은 n + 1만큼
- 0층을 초기화한다.
    - 반복문을 통해 0층의 i호를 i로 선언한다.
- 이후 k층까지 반복해서 다음과 같이 할당한다.
    - k층에 n - 1호는 k층에 n호 바로 아랫집인 k - 1층 n호를 제외한 사람의 수만큼 살고있다.
      e.g.) 1층 3호는 0층의 1호부터 3호까지 사는 사람의 총 인원을 알고 있어야 한다.
            이때 1층 2호는 0층의 1호와 2호에 사는 사람만큼 거주하고 있다.
            그러므로 1층 3호는 0층의 3호에 사는 사람, 그리고 1층의 2호에 사는 사람의 수를 합한 인원을 통해 몇명이 들어와야 하는지 알 수 있다.
    - 따라서 k층 n호 = (k - 1층 n호) + (k층 n - 1호)를 만족한다.
