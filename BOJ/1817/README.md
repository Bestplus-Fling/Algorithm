# [BOJ 1817 - 짐 챙기는 숌](https://www.acmicpc.net/problem/1817)
- 난이도: 실버 5
- 분류: 구현, 그리디, 시뮬레이션
- 날짜: 2026-02-20

## 문제
- 숌은 책을 박스에 차곡차곡 넣어서 택배로 미리 보내려고 한다. 책은 탑처럼 차곡차곡 쌓여있기 때문에, 차례대로 박스에 넣을 수밖에 없다.
- 각각의 책은 무게가 있다. 그리고 박스는 최대 넣을수 있는 무게가 있다. 숌이 필요한 박스의 개수의 최솟값을 구하는 프로그램을 작성하시오.

## 조건
- N은 0보다 크거나 같고 50보다 작거나 같은 정수이고, M은 1,000보다 작거나 같은 자연수이다.
- 둘째 줄에 책의 무게가 공백을 사이에 두고 주어진다. 책의 무게는 M보다 작거나 같은 자연수이다.
- 만약 N이 0이라면, 둘째 줄은 주어지지 않는다.

## 접근
- 1. N이 0일때 - 책이 없을 때
     - 0 출력
- 2. N이 0이 아닐 때
    - 상자를 가지고 시작하므로 최초 ret값은 1
    - a. 만약 상자에 책을 채웠을 때 M보다 작거나 같다면 
        - 상자의 책을 담을 수 있다
        - 상자에 책 무게를 더한다.
    - b. M보다 크다면(책을 넣을 수 없다면)
        - 상자를 추가한다.
        - 추가한 상자에 현재 책을 담는다.
