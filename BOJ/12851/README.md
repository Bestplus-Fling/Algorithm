# [BOJ 12851 - 숨바꼭질 2](https://www.acmicpc.net/problem/12851)
- 난이도: 골드 4
- 분류: 
- 날짜: 2026-02-14

## 문제
- 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에
- 동생은 점 K(0 ≤ K ≤ 100,000)에 있다

- 수빈이는 걷거나(x + 1, x - 1), 순간이동을 할 수 있다(2 * x)
- 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 그리고, 가장 빠른 시간으로 찾는 방법이 몇 가지 인지 구하는 프로그램을 작성하시오.

## 조건
- N(0 ≤ N ≤ 100,000)
- K(0 ≤ K ≤ 100,000)
- N과 K는 정수

# 접근
- 시작 위치가 동일 하거나 동생이 수빈이보다 뒤에 있는 경우(n >= k)
    - x - 1만으로 움직일 수 있으며 경우는 1가지
    - 따라서 n - k와 1을 출력한다.
- 시작 위치가 동생보다 작을 경우(n < k)
    - BFS 탐색을 통해 찾을 수 있다.
    - 이때 visited가 시간을 기록하며, 가장 빨리 k위치에 도달했을 경우와 그와 비슷한 경우들에 대해서 카운팅한다.
