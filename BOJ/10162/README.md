# [BOJ 10162 - 전자레인지](https://www.acmicpc.net/problem/10162)
- 난이도: 브론즈 3
- 분류: 수학, 구현, 그리디
- 날짜: 2026-02-21

## 문제
- 3개의 시간조절용 버튼 A B C가 달린 전자레인지가 있다
    - 버튼 A, B, C에 지정된 시간은 각각 5분, 1분, 10초이다.
- A, B, C 3개의 버튼을 적절히 눌러서 그 시간의 합이 정확히 T초가 되도록 해야 한다
- 만일 제시된 3개의 버튼으로 T초를 맞출 수 없으면 음수 -1을 첫 줄에 출력해야 한다.
    
## 조건
- 1 ≤ T ≤ 10,000


## 접근
- 가장 작은 수가 10초이므로 만약 10으로 나눈 나머지가 0이 아니라면, 정확히 T초를 맞출 수 없으므로 -1 출력
- 이외의 경우에 조작해야 할 버튼을 누른 숫자를 언패킹하여 출력
