# [BOJ 17478 - 재귀함수가 뭔가요?](https://www.acmicpc.net/problem/17478)
- 난이도: Silver 5
- 분류: 구현, 재귀
- 날짜: 2026-02-18

## 문제
- 재귀함수가 무엇인지 물어보는 학생들을 위한 응답을 출력하는 프로그램을 만들어보자.
- 출력 예시를 보고 재귀 횟수에 따른 챗봇의 응답을 출력한다.

## 조건
- 재귀 횟수 N(1 ≤ N ≤ 50)

## 접근
- 재귀의 깊이가 깊어지면 "_"(언더스코어)가 4개씩 증가한다.
- f-string으로 언더스코어와 문자열을 결합하여 출력한다.
