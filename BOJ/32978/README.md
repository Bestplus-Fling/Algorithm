# [BOJ 32978 - 아 맞다 마늘](https://www.acmicpc.net/problem/32978)
- 난이도: 실버 5
- 분류: 자료구조, 문자열, 정렬, 집합과 맵
- 날짜: 2026-02-22

## 문제
- 각 학생이 좋아하는 학생은 1명 이상 주어지고, 내가 나를 좋아하는 예는 없다.
- 나를 좋아하는 학생이 많을수록 나의 인기도가 높다. 
- 인기도가 높은 학생부터 낮은 학생 순으로 학생 이름과 해당 학생을 좋아하는 학생 수를 출력하자. 인기도가 같은 경우 학생 이름 기준으로 오름차순으로 출력하자.

## 조건
- 3 ≤ n ≤ 100
- 1 ≤ 학생 이름 길이 ≤ 10

## 접근
- 처음 총 학생의 이름을 입력받았을 때, 이를 key로 한 dict를 생성
- 이후 n개의 줄에서 좋아하는 학생을 +1 증가한다.
- 마지막에 dict.items() 메서드를 사용하여 key value 쌍을 정렬한다.
    - 이때 정렬은 value 내림차순, key 오름차순이다.
