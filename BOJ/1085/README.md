# [BOJ 1085 - 직사각형에서 탈출](https://www.acmicpc.net/problem/1085)
- 난이도: 브론즈 3
- 분류: 기하학
- 날짜: 2026-02-19

## 문제
- (x, y)에서 
  왼쪽 아래 꼭짓점은 (0, 0), 
  오른쪽 위 꼭짓점은 (w, h)인 
  직사각형의 경계선까지 가는 거리의 최소값

## 조건
- 1 ≤ w, h ≤ 1,000
- 1 ≤ x ≤ w-1
- 1 ≤ y ≤ h-1
- x, y, w, h는 정수

## 접근
- a: x에서 0 혹은 w까지 가는 거리 중 작은 것을 선택
- b: y에서 0 혹은 h까지 가는 거리 중 작은 것을 선택
- a와 b 중 작은 것을 출력
