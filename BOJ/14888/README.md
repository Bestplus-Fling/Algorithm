# [BOJ 14888 - 연산자 끼워넣기](https://www.acmicpc.net/problem/14888)
- 난이도: 실버 1
- 분류: 백트래킹
- 날짜: 2026-02-09

## 문제
- N개의 수로 이루어진 수열이 주어진다.
- 수와 수 사이에 끼워 넣을 수 있는 N-1개의 연산자가 주어진다.
- 수와 수 사이에 연산자를 하나씩 넣어서 수식을 하나 만들 수 있다.
- 식의 결과가 최대인 것과 최소인 것을 구하라

## 조건
- N(2 ≤ N ≤ 11)
- A1, A2, ..., AN(1 ≤ Ai ≤ 100) 

## 접근
- 재귀를 통해 식이 완성되면 최대 최소인지 검증한다.
    - 완성된 식을 계산할 때 우선순위는 무시된다.
  
## 특이사항
- 문제에서 나눗셈은 c++의 나눗셈을 요구한다.
  - `a = bq + r`
  - 위 방법으로 7 / -3을 하면 -2가 몫이 된다.
- 파이썬에서는 다른 방식으로 나눗셈의 몫을 취한다.
  - 파이썬에서 7 // -3을 하면 몫이 -3이 나온다.
  - 따라서 `int(x / y)`와 같은 방법으로 몫을 구할 필요가 있다.
