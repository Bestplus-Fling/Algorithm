# [BOJ 25305 - 커트라인](https://www.acmicpc.net/problem/25305)
- 난이도: 브론즈 2
- 분류: 정렬
- 날짜: 2026-02-29

## 문제
- N명이 학생 중 점수가 가장 높은 k명은 상을 받는다
- 이때 상을 받는 커트라인이 몇 점인지 구하라

## 조건
- 1 ≤ N ≤ 1,000
- 1 ≤ k ≤ N
- 0 ≤ x ≤ 10,000

## 접근
- 경우 1: N명의 학생이 모두 상을 받는 경우(N == k)
    - N명 가운데 최저점을 반환한다.
- 경우 2: N명 가운데 k명만 상을 받는 경우
    - 오름차순 정렬 후 `[k-1]`에 위치한 점수를 출력
