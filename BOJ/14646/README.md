  - 1회: Fail

  - 2회: Solve

## 문제
- N개의 중복되지 않는 메뉴들과 커다란 돌림판이 존재
- 돌림판을 N개의 칸으로 균일하게 나눈 뒤, N개의 메뉴를 각각 한번씩 써 넣는다.
- 0: 돌림판을 돌리고 돌림판에 걸린 칸을 확인한다.
- 1: 걸린 칸에 스티커가 붙어있지 않다면, 스티커를 하나 붙인다.
- 2: 걸린 칸에 스티커가 붙어있다면, 식단표에 해당하는 메뉴를 적어놓고 그 칸을 제거한다.
    - 스티커도 떼어낸다.
    - 어떤 칸이 제거되면 다음부터는 그 칸에 절대로 멈추지 않는다.
- 3: 모든 칸이 제거될 때 까지 0, 1, 2를 반복한다.

- 총 2N번 돌리면 N일 동안의 메뉴를 모두 정할 수 있다.
- **돌림판에는 최대 몇 개의 스티커가 붙어있을 수 있을까.**

## 조건
- 1 <= N <= 100,000
- 메뉴는 1부터 N 까지의 자연수(1 <= 메뉴 <= N)

## 접근
### 1. 메뉴가 선택되기 전과 선택된 이후의 차이
- 메뉴가 한번 선택됐을 때 스티커 개수 +1
- 이미 스티커가 붙은 메뉴가 선택됐을 때 비교를 통해 최대 개수를 저장 수 -1
