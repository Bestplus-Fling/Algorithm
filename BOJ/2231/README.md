# [BOJ 1541 - 분해합](https://www.acmicpc.net/problem/2231)
- 난이도: 브론드 2
- 날짜: 2026-02-02
- 제출: 2회
    - 1회: 생성자가 없는 경우 0 출력을 생략
    - 2회: 0 출력 추가 후 solve
    - 3회: 최소값을 찾으면 되므로 정방향 순회를 통해 찾자 마자 break 시도
## 문제
- 분해합을 했을 때 N을 만족하는 생성자가 최소인 것
- 생성자가 없을 경우 0을 출력


## 조건
- 자연수 N(1 <= N <= 1,000,000)

## 접근
- N부터 1까지 순회하며 i가 생성자를 만족하는지 판별
  ```py
  for i in range(n - 1, 0, -1):
    x = i + sum(map(int, str(i)[::]))
  ``` 
- 만약 생성자일 경우 갱신
    - 문제에서 최소값을 요구했기 때문에 다른 조건 확인 필요 없이 갱신해도 무관
