# [BOJ 2580 - 스도쿠](https://www.acmicpc.net/problem/2580)
- 난이도: 골드 4
- 분류: 구현, 백트래킹
- 날짜: 2026-02-11

## 문제
- 게임 시작 전 스도쿠 판에 쓰여 있는 숫자들의 정보가 주어질 때 모든 빈 칸이 채워진 최종 모습을 출력하는 프로그램을 작성하시오.

## 조건
- 아홉 줄에 걸쳐 한 줄에 9개씩 게임 시작 전 스도쿠판 각 줄에 쓰여 있는 숫자가 한 칸씩 띄워서 차례로 주어진다.
- 스도쿠 판의 빈 칸의 경우에는 0이 주어진다.

## 접근
- 1. 입력 시 0이 주어지는 좌표를 기록한다.
- 2. 기록한 좌표값에 따라 3 * 3영역 및 행렬에 대해 검사를 진행한다.
- 3. 해당 칸에서 가능한 숫자만 가지고 검증을 진행한다.
    - 이미 존재하는 수를 제거한다.
    - 배열 형태로 반환한 뒤 해당 좌표의 재귀 진행시 사용한다.
### 검사 방법의 문제
- 기존에는 행렬 9번, 3*3 박스 9번의 검사를 for문으로 반복
  - 이로 인해 시간 초과 발생
  - 대안: 배열 형태로 행렬에서 이미 사용된 숫자인지 검사하는 배열을 통해 공간복잡도를 높이고 시간복잡도를 낮춤
### 정답을 찾아도 재귀 반복
- 함수에서 정답을 찾으면 `return True`로 재귀를 탈출하도록 설계
