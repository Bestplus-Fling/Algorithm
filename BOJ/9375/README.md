# [BOJ 9375 - 패션왕 신해빈](https://www.acmicpc.net/problem/9375)
- 난이도: 실버 3
- 분류: 시뮬레이션
- 날짜: 2026-02-08

## 문제
- 한번 입었던 옷들의 조합을 절대 다시 입지 않는다
- ex) 안경, 코트, 상의, 신발을 입었다면?
    - 다음날은 바지를 추가로 입거나
    - 안경 대신 렌즈를 착용해야 한다.
- 알몸이 아닌 상태로 며칠동안 밖에 돌아다닐 수 있을까

## 조건
- 테스트케이트 최대 100
- 의상 수 n: 0 <= n <= 30
- n개의 의상 이름과 의상 종류가 공백으로 구분되어 주어진다.
    - 같은 종류의 의상은 하나만 입을 수 있다.

## 접근
### 1. 재귀 조합
- 최소 1개 이상, 카테고리 개수 이하의 중복 없는 조합
- 카테고리별 의상 개수의 합 + 조합
### 2. 조합 계산
- 한 카테고리에서 선택할 가능성은
  - 카테고리에 해당하는 옷을 입는다
  - 안입는다
- 따라서 (category에 해당하는 옷 개수) + 1이고
- 모든 카테고리에 대해서 곱셈을 진행한다.
- 마지막에 모든 카테고리에서 안입는다의 경우를 제외하기 위해
- -1을 한다.
